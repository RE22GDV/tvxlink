Перша робота програми (тоді вона ще звалася TVExplorer) зі справжнім PROMAX TV EXPLORER II+
(лабораторний ноутбук, Windows 11, Python 3.13.17, драйвер TI TUSB3410 → COM3). Нижче за часом:
яку команду запускали, що вивела консоль, що з цього випливає і що після цього виправлено в
програмі.

> Тодішня версія програми писала повідомлення російською. Для цього репозиторію їх перекладено
> українською — тут і в усіх файлах цієї папки. Команди, відповіді приладу, hex-байти, числа й час
> не змінювалися. Види, джерела й підсумки у файлах даних переведено в коди поточної програми.

| Формат BER | `[прапорець][знак][2 цифри]E[порядок]`, звичайне число: `CB>+10E-2` = «>1.0E-1» |
| Масштаб LV/CN/ME, одиниці FR | ×10 і кГц — правильно |
| Коди `*?ST` | 6 = «MPEG-2 TS DVB-S», 8 (у DVB-S2) — захоплено, 0 у DVB-S = «No signal received» |
| Чи відповідає прилад на `*?SA`, `*?ST` | так |
| Витримка після `*FR` | рівень встановлюється за 0,77 с |
| Коли NAK на вимірювання | на екрані картинки каналу (режим ТБ); на екрані вимірювань — відповідає |
| DVB-S2 через USB | при захопленні відповідає, LBER приходить як `VB<+10E-9` / `VB +36E-9` |

Відкрито: даталогер (`*?FI0A` — NAK), проміжні коди `*?ST` (Signal received, Carrier recovered,
Viterbi synchronized), підписи `*?ST` у режимі DVB-S2.
